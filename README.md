# Войти в IT

## Локальный запуск

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
plocal
```

Команда `plocal` запускает Flask на `http://127.0.0.1:5001` (порт 5000 занят macOS AirTunes). Остановить сервер: `Ctrl+C`. Другой порт можно выбрать так: `PORT=5050 plocal`.

## Подготовка Ubuntu/Debian-сервера

Проверьте, что DNS-запись домена `vhudoverdiev.ru` указывает на сервер. После отправки кода в GitHub клонируйте репозиторий на сервер и выполните:

```sh
bash deploy/setup_server.sh
```

Скрипт устанавливает Nginx, MariaDB и Python, создаёт отдельную базу `vhiti`, системного пользователя, systemd unit и сайт Nginx. Перед настройкой он сохраняет конфигурацию Nginx и список сервисов в `/root/vhiti-setup-backup-*`. Если Nginx уже настроен на этот домен, скрипт остановится и ничего не перезапишет. После HTTP-проверки создайте администратора командой, которую скрипт выведет, и подключите HTTPS:

```sh
certbot --nginx -d vhudoverdiev.ru
```

После запуска нового сайта и проверки домена удалите прежний проект командой `bash deploy/cleanup_legacy.sh`. Скрипт сначала проверяет новый `vhiti` и его HTTP-ответ; при ошибке старый сайт не трогает. Затем удаляет старый Gunicorn, Nginx-сайт `peredacha`, базу `peredacha`, каталог `/opt/peredacha` и старый сертификат `akvilon-peredacha.ru`. Снимок конфигурации Nginx/systemd сохраняется в root-only каталоге `/root/legacy-nginx-config-*`. Новая база отдельная: `vhiti`.

## Деплой и загрузка курсов командой `pdeploy`

Для обновления интерфейса и кода без синхронизации видеоматериалов выполните `pdeploy --code-only`. Команда отправляет изменения в GitHub и запускает выпуск приложения на сервере; размер папки курсов при этом не проверяется, файлы видео не передаются. Тесты из 10 вопросов доступны после каждого урока оставшихся импортированных курсов; банки составлены по темам разделов с повторением базовых понятий. Ответы и попытки привязаны к конкретному уроку.


Измените файлы проекта и выполните `pdeploy` в терминале. Команда коммитит изменения, отправляет `main` в GitHub, подключается к серверу по SSH, синхронизирует папки `Курсы/2` и `Курсы/3`, выполняет миграции, импортирует эти курсы и проверяет сервис. Курс 4 пока остаётся локально; его можно загрузить отдельно позже. Медиа остаются вне Git в `/opt/vhiti/instance/media`; перед синхронизацией команда сверяет свободное место с размером выбранных курсов и запасом 2 ГБ. При прерывании `rsync` продолжит неполные файлы при следующем запуске.

Путь к папке с курсами по умолчанию `/Users/khudoverdiev/Desktop/Сайты/vhudoverdiev/Курсы`; его можно переопределить через `PDEPLOY_COURSES_DIR`. Сервер по умолчанию `root@135.106.139.229`; можно задать `PDEPLOY_USER` и `PDEPLOY_HOST`.

На Mac для парольного SSH нужен `expect` (`brew install expect`). Пароль вводится один раз и не сохраняется в проекте или Git. При первом соединении подтвердите проверенный ключ сервера. Публикация в GitHub требует настроенной авторизации Git (например, `gh auth login`, SSH-ключ или credential helper). Не храните пароль сервера в скриптах.

Управление аккаунтами доступно только из терминала: `flask --app wsgi.py create-user`. Команда запрашивает имя, почту и пароль ученика; доступом и ручными зачётами управляет отдельная админ-страница `/admin/progress`.

Курс AI Developer снят владельцем: выпуск приложения удаляет его уроки, попытки, прогресс и серверную папку `instance/media/courses/1`. Папка 1 исключена из импорта и синхронизации. Локальные исходники курса остаются в `Курсы/1`.

Тест проходит по одному вопросу: выбор ответа сразу оценивается сервером, показывается разбор, затем через 6 секунд открывается следующий вопрос. Автопереход можно остановить. Проходной балл — 5 из 10. Версии наборов проверяются: результаты прежних общих тестов не подменяют новые попытки. Для английского используются 21 отдельный тематический набор по названиям видеозанятий; это авторские проверки темы, а не извлечение из расшифровок.

Программа курса показывает отдельный статус каждого урока. Завершение учебного урока требует сданного теста (не менее 5 из 10); прежние успешные попытки продолжают учитываться, просмотр видео хранится отдельно. Доступ к последующим урокам, медиа, ресурсам и тестам проверяется сервером. Библиотека собеседований остаётся со свободным порядком просмотра. После успешного теста показывается одно из шести поздравлений с вариациями частиц и без повторения сцены подряд; при уменьшенном движении эффекты отключены.

Админ-страница «Прогресс учеников» доступна только аккаунтам `is_admin`. Можно выбрать ученика и курс, открыть раздел или отдельный урок, зачесть урок/раздел на 10/10. Ручные зачёты сохраняются отдельно в `learning_override` с идентификатором администратора и временем, не подменяют ответы и не зависят от версии вопросов. Успешный старый тест темы засчитывает уроки соответствующей темы; результаты прежних тестов сохраняют исходные баллы и количество вопросов.
